

# 版本开发计划

### v0.1.0 版本（基础可用版）
版本定位：日志库最小可运行版本，仅实现核心基础日志输出能力
1. 支持 Debug/Info/Warn/Error/Fatal/Panic 6个基础日志级别，级别可动态配置
2. 支持通过代码动态配置开启/关闭指定日志级别
3. 支持 JSON/txt 格式结构化日志输出，包含 msg、level、time 三个核心字段
4. 自动添加时间、日志级别、调用文件路径、行号元信息
5. 支持字符串、数字、结构体、bool、time.Time、error 类型的基础格式化输出
6. 实现基础互斥锁机制，保证多goroutine并发写入日志无错乱
7. 支持同时将日志输出到控制台+本地文件，日志输出目标可配置
8. 实现 panic 异常捕获，输出完整的堆栈信息
9. 提供兼容 Go 标准库 log 的接口，支持存量代码平滑迁移

### v0.2.0 版本（功能增强版）
版本定位：补充基础输出能力，适配简单文件输出场景

1. 支持全局添加固定自定义字段（如服务名、版本号）
2. 支持通过 YAML/JSON 配置文件管理日志行为（替代硬编码）
3. 实现基础版日志轮转，支持按文件大小切割日志（单文件达100MB自动切割，支持保留最近5个切割后的日志文件）、按时间（按天/小时，支持按保留时长清理日志，如保留最近7天日志）切割日志
4. 实现日志归档能力，自动压缩超期日志文件
5. 日志自动携带 goroutine ID、主机名元信息
6. 适配 context.Context，支持提取并输出 trace_id/request_id 链路字段

### v0.3.0 版本（性能优化版）
版本定位：提升性能 + 补充链路追踪能力，适配高并发测试场景
1. 替换基础锁机制，实现无锁日志写入逻辑
2. 优化并发写入逻辑，降低基础锁机制的性能损耗
3. 新增日志异步写入能力，通过内存缓冲区+后台协程批量写入
6. 优化 JSON 日志序列化性能，减少内存分配

### v0.4.0 版本（生产级完善版）
版本定位：补充全量生产级能力，适配线上生产环境
1. 支持自定义 Hook 机制（如 Error 级别日志触发钉钉/邮件告警）
2. 支持通过 HTTP 接口运行时动态调整日志级别（无需重启服务）
3. 实现日志采样功能，支持按比例采样 Debug/Info 级别日志（如 10% 采样率）
4. 支持日志输出到TCP/UDP网络目标（扩展输出能力）
5. 完善日志异常处理机制，写入失败时提供降级策略（如临时输出到控制台）
